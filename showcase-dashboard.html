The fork

Nineteen lines. Palette values and semantic reassignment only — no primitive is touched, and r = P/2 is untouched, so the geometry is identical to every other surface.

#dashSurface{
  --neelam-100: #E7ECF7;  --neelam-500: #33509B;
  --neelam-600: #2F4A8C;  --neelam-350: #9DB6E8;
  --neelam-900: #1B2333;

  --color-accent:        var(--neelam-500);
  --color-accent-hover:  var(--neelam-600);
  --color-accent-subtle: var(--neelam-100);
  --color-on-accent:     var(--maa-50);
  --color-kolam-line:    var(--neelam-500);
}
:root[data-theme="dark"] #dashSurface{
  --color-accent:        var(--neelam-350);
  --color-accent-subtle: var(--neelam-900);
  --color-on-accent:     var(--mann-900);
}
Note what is absent. No spacing, no radius, no type, no motion, no component override. Everything structural came from the system, which is the only reason a fork can be this short.

What it stresses

Held up

  • Compact density. Every gap tightens by 25% and the hierarchy still reads, because proximity ratios are preserved — everything scales by the same factor.
  • Type staying fixed. This is the payoff for not coupling type to pitch. The table is denser; it is not smaller to read.
  • Charts on semantic colour. Series use --color-accent, --color-warning, --color-danger, so they fork and theme with everything else and never need a chart palette of their own.
  • Three elevation levels. A console with cards, a rail and a table needed no more depth than surface stepping plus one hairline shadow.

Broke, and the fix

  • Rail targets. Navigation items sized on --alavu-sm resolve to 24px at P = 6. Visually correct for a dense console, and an accessibility failure on touch. Fixed by setting min-height: var(--alavu-md) on the rail items — compact appearance, 44px target.
  • Table row actions. Same problem, same shape of fix. btn-sm is a visual size, never a target guarantee. This is the distinction the target size section insists on, and it is easy to get wrong precisely because the design looks right.
No pattern, on purpose. An operations console is scanned under pressure. The 10% density ceiling would technically allow a faint ground here, and it would still be the wrong call — the expressive layer has to earn its place per surface, not per system.
